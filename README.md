# Официальный сайт группы "Хамам"

Шуточный официальный сайт-визитка группы друзей "Хамам" (также "Хаммамм").

## О проекте

Это НЕ бизнес-сайт — это юмористический сайт-визитка группы из 4 друзей, которые познакомились в игре PEAK в 2026 году. Сайт пародирует корпоративные сайты, но рассказывает настоящую историю дружбы.

## Структура сайта

- **Главная страница** (`index.html`) — приветствие, статистика группы, краткая информация
- **История** (`history.html`) — таймлайн событий с момента основания группы
- **Участники** (`members.html`) — список всех четырёх участников
  - Индивидуальные страницы каждого участника:
    - `losok_shirokiy.html` — Основатель и CEO
    - `grib.html` — Главный Мост
    - `izumrud.html` — Крёстный отец названия
    - `mark.html` — Специальный агент
- **Анкета** (`anketa.html`) — форма для желающих стать друзьями группы

## Особенности

### Функционал анкеты
- Шуточная форма с забавными полями (должность в "Хамаме", любимая цитата и т.д.)
- Сохранение данных в localStorage браузера
- Возможность редактирования и удаления сохранённой анкеты
- При повторном заходе пользователь видит свою анкету

### Пасхалки
- Счётчик "дней без ссор" на главной странице
- Секретная кнопка "НЕ НАЖИМАТЬ"
- Шуточные должности и цитаты участников

### Технологии
- Чистый HTML5
- CSS3 с современным дизайном
- Vanilla JavaScript (без фреймворков)
- Адаптивный дизайн для мобильных устройств
- LocalStorage для хранения данных анкеты

## Запуск проекта

### Локальный запуск

#### Вариант 1: Python HTTP сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# Или Python 2
python -m SimpleHTTPServer 8000
```

Затем откройте в браузере: `http://localhost:8000`

#### Вариант 2: Node.js http-server

```bash
# Установите http-server глобально (один раз)
npm install -g http-server

# Запустите сервер
http-server -p 8000
```

Затем откройте в браузере: `http://localhost:8000`

#### Вариант 3: VS Code Live Server

1. Установите расширение "Live Server" в VS Code
2. Откройте `index.html`
3. Нажмите "Go Live" в нижнем правом углу

#### Вариант 4: Открыть файл напрямую

Просто откройте `index.html` в браузере двойным кликом.
**Примечание:** некоторые функции могут не работать из-за ограничений CORS.

### Деплой на хостинг

#### GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub
2. Загрузите все файлы проекта
3. Перейдите в Settings → Pages
4. В разделе "Source" выберите ветку `main` и папку `/root`
5. Сохраните — сайт будет доступен по адресу `https://ваш-username.github.io/название-репозитория/`

#### Netlify (бесплатно)

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку проекта в Netlify Drop
3. Сайт автоматически опубликуется

#### Vercel (бесплатно)

1. Установите Vercel CLI: `npm i -g vercel`
2. В папке проекта выполните: `vercel`
3. Следуйте инструкциям в консоли
